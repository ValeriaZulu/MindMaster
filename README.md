## 📱 Características

- **Desafío por Niveles**: Progresión de dificultad desde Novato hasta Experto con desbloqueo secuencial de retos.
- **Banco de Preguntas Local**: Sistema de trivias categorizado (Cultura, Ciencia, Tecnología, etc.) optimizado para funcionamiento offline y alto rendimiento.
- **Sistema de Puntuación**: Registro dinámico de puntos y seguimiento de progreso detallado por cada nivel completado.
- **Interfaz Adaptativa**: Diseño *Mobile-First* que utiliza un Layout inteligente para verse como app nativa en celulares y como contenedor elegante en escritorio.
- **Ranking Global**: Visualización de los mejores puntajes para fomentar la competitividad entre los usuarios.
- **Personalización de Perfil**: Gestión de identidad del usuario, incluyendo nombre personalizado y estadísticas de juego.
- **Experiencia Fluida**: Animaciones de alta fidelidad y transiciones rápidas para una jugabilidad inmersiva.

## 🛠️ Tecnologías

- `vite >= 5.4.11`
- `react >= 18.3.1`
- `typescript >= 5.6.2`
- `tailwindcss >= 3.4.17`
- `zustand` - Gestión de estado global para la lógica del juego y persistencia de puntos.
- `react-router-dom` - Enrutamiento SPA para una navegación fluida entre pantallas.
- `lucide-react` - Librería de iconos vectoriales para una interfaz limpia.
- `framer-motion` - Orquestación de animaciones e interacciones de UI.
- `confetti-canvas` - Feedback visual tras completar niveles exitosamente.

## 📋 Requisitos

- `Node.js >= 18.0.0`
- `npm >= 10.0.0`

## 🚀 Instalación

1. **Clonar el repositorio**
```bash
git clone [https://github.com/ValeriaZulu/MindMaster](https://github.com/ValeriZulu/MindMaster)
cd mindmaster
```

2. **Instalar dependencias**
```bash 
npm install
```

3. **Iniciar el servidor de desarrollo**
```bash 
npm run dev -- --host
```
> ⚠️ El parámetro `--host` permite acceder a la aplicación desde otros dispositivos en la misma red local.

4. **Compilar para Producción**
```bash
npm run build
```
